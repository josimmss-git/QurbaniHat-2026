# QurbaniHat - Livestock Booking Platform

## Project Purpose

QurbaniHat is a modern livestock booking platform where users can browse available animals, view detailed information, and book animals online for Qurbani. The platform provides a simple and user-friendly experience for finding and reserving livestock.

## Live URL

https://your-live-site-url.vercel.app

## Features

* Browse all available animals
* View detailed information for each animal
* Featured animals section on the homepage
* Animal booking system
* User authentication (Sign Up & Sign In)
* Responsive design for mobile, tablet, and desktop
* Dynamic routing with Next.js App Router
* Modern UI built with HeroUI and Tailwind CSS

